Student Result Management System (Week 1)

Overview
This is a Dart Console Application developed as part of the Week 1 assignment. The application allows users to enter a student's name and marks for three subjects, then calculates the total marks, percentage, grade, and pass/fail status.

Features
- Enter student name
- Input marks for 3 subjects
- Calculate total marks
- Calculate percentage
- Assign grade (A, B, C, D, Fail)
- Display pass/fail status
- Input validation
- Exception handling for invalid input

Concepts Used
- Variables
- Data Types
- Functions
- Lists
- Loops
- Conditional Statements
- User Input
- Exception Handling
- Dart Console Programming

Grading Criteria

| Percentage | Grade |
|------------|-------|
| 80% and above | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 50% - 59% | D |
| Below 50% | Fail |

How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open Terminal.
4. Run the following command:

```bash
dart run student_result_management_system.dart
```
